# Rewoven — upcycled fashion marketplace (landing-page MVP)

Rewoven is a multi-vendor marketplace for upcycled fashion: independent
upcyclers, thrift tailors and designers list one-of-a-kind reworked clothes.
Rewoven earns 5%–15% commission on each sale.

This repo holds the MVP landing site (TanStack Start app: React + Vite +
Tailwind), served on port 3000.

## What's in the MVP

- Landing page (`src/routes/index.tsx`): what Rewoven is, how selling works
  including commission, upcycling / brand-safety rules, example one-of-a-kind
  pieces (`public/images/piece-1.png`, `piece-2.png`, `piece-3.png`).
- Seller & buyer waitlist signup forms (POST to `/api/waitlist`).
- Request-a-piece flow (POST to `/api/requests`).
- `/admin` page + `/api/admin-data` route to review signups and requests.
- API routes: `src/routes/api/waitlist.ts`, `src/routes/api/requests.ts`,
  `src/routes/api/admin-data.ts`. Optional Postgres via `src/db.ts`
  (`DATABASE_URL`, Neon serverless); file fallback otherwise.
- Hosting scripts: `publish.sh` / `go-live.sh`, `serve.ts`, `vercel-entry.ts`,
  `build-vercel.sh`.

## Run it

Requires [Bun](https://bun.sh).

```bash
bun install
bun run dev      # local dev
# production-style serve:
bun run build && bun run start
```

`src/routeTree.gen.ts` is generated by the TanStack Start router plugin on
dev/build — do not edit it by hand.

## Brand-safety rules (enforced in copy + listing policy)

Focus on unbranded thrift finds, vintage blanks and deadstock fabrics.
Branded pieces are only allowed if the silhouette is transformed and no
third-party logo is the selling point; every listing must be clearly
independent and not affiliated with or endorsed by any original brand.
